# Change Spec：移动端模型设置原型

## 当前系统现状

M03 设置页没有模型入口；M07 是未进入目录的占位页。`docs/new-product` 是静态原型，M01–M06 共用 `mobile.css`/`mobile.js`。真实模型与 Provider 由桌面/Cloud 的受保护 API 管理，API Key 不得进入普通列表响应、日志或二维码。

## 目标与范围

从 M03 进入 M07；顶部返回、标题、扫码和添加；主体按来源分组，按模型展示卡片。提供厂商选择、服务商/URL/API Key、从 `/models` 获取可多选的模型、上下文参数、编辑和删除确认。只实现静态原型交互和当前页面内状态，不修改生产 API、数据库或原生移动端。扫码只识别一次性配对码，真实凭据交换仍由受保护的配对协议完成。

## 安全与冲突

模型目录请求只向用户填写的 HTTPS/localhost URL 发起；API Key 仅随用户点击获取列表的请求发送，不写入 DOM、localStorage 或日志。原型不在二维码中传输永久密钥；扫描成功不表示配置已同步。保持现有 M03/M01–M06 交互不变。

## 验收

- M03 模型设置入口可进入 M07，返回可回 M03。
- 多模型按来源分组、每模型一张卡片；列表剩余区域可滚动。
- 添加、编辑、多选、获取列表的加载/失败、删除确认状态可操作；取消删除不改变列表。
- 扫码缺少设备/浏览器支持时显示明确不可用状态，不虚报成功。
- `node --check`、产品文档校验、浏览器交互检查通过。
