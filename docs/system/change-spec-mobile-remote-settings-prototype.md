# Change Spec：移动端远程设置与模型连接测试原型

## 当前系统现状

`docs/new-product` 是独立静态交互原型。M03 已有模型设置入口，M07 的模型表单支持配置与目录读取，但没有运行时连接测试；M08 仍是占位页。真实 Cloud 使用短时一次性配对码、设备公钥、Grant 和受保护的 Relay/LAN 握手；普通模型/设备列表不返回密钥。

## 目标与范围

在 M07 编辑表单增加“测试连接”，向用户配置的 OpenAI-compatible 地址发送最小非流式请求并反馈成功/失败。M03 增加远程连接入口；M08 展示按云端分组的连接和客户端设备，提供添加、编辑、删除确认与两种扫码入口。原型的连接配置仅在当前页面内存中，状态显示“未验证”，不写生产 API、数据库或原生移动端。

## 冲突与安全边界

模型测试只在用户点击后向其填写的 HTTPS/本机 URL 发送请求，限时中止，错误不回显 Provider body、密钥或请求内容。扫码只接受带类型的一次性配对码；二维码不能携带长期凭证。扫码后仅打开预填表单，不宣称完成认证、设备授权、在线探测或远控连接。凭证不写入 DOM 回填、持久存储、日志或原型二维码。真实联通须由已有 Cloud 配对、device proof、Grant 与加密传输协议完成。

## 影响与验收

影响 M03、M07、M08、移动端页面目录和 feature registry；不影响发布服务或现有数据。验证入口导航、模型测试的输入校验和超时/失败提示、远程表单回填、分组、删除取消/确认、扫码分型与不可用状态。运行 JS 语法、产品文档校验，并浏览器检查关键交互。回滚只需移除原型页增量和入口。

浏览器回归中发现 M07 异步请求回调在 `await` 后读取 `event.currentTarget`，会使测试/目录按钮停留在禁用态；两处均改为请求前保存按钮引用。回归需确认失败后按钮可再次点击。
