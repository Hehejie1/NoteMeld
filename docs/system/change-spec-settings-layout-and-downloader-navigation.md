# 设置布局与下载器导航修复

更新时间：2026-09-23

## 当前现状

- 模型设置由设置分类栏、供应商列表和编辑表单组成；模型页的表单 flex 子项未显式允许收缩，编辑表单限制最大宽度。
- 下载器设置由平台列表和 Cookie 表单组成。平台项使用固定浅色颜色，并以带点击处理器的 `div` 导航。
- 两处均只影响桌面前端呈现和导航语义，不修改后端、数据、API 或凭据处理。

## 目标与范围

- 在窄窗口宽度下让模型列表和表单在各自栏位内收缩、滚动，避免横向溢出和内容裁切。
- 统一模型设置内容区表面颜色，避免主题下出现明显的父子底色断层。
- 下载器平台导航使用主题语义颜色、明确的选中/焦点状态，并可用键盘访问。
- 下载器表单在内容区内保持合理阅读宽度并居中。

不改变模型供应商、Cookie 的 API、保存逻辑、字段校验或数据结构；不重做设置 IA。

## 冲突与影响

- 不触及产品规则、数据模型、API 契约和 known-pitfalls 中的状态/持久化边界。
- 仅影响 `desktop/frontend` 设置页面；不影响桌面 sidecar、源码启动、CLI、MCP、迁移或打包。
- 使用现有 Tailwind 语义 token 与 React Router 导航，不新增组件系统或状态源。

## 验收

- 模型设置栏位在可用宽度较小时不把内容挤出视口，编辑区无横向滚动和裁切。
- 模型设置父子区域在深色主题中使用连续一致的表面色。
- 下载器平台项可 Tab 聚焦、回车导航，当前平台有可辨识的选中态和可见焦点态，浅色/深色主题均可读。
- Cookie 表单继续读取、编辑并提交原有字段。回归建议：前端契约/build 检查，以及桌面端窄/宽窗口、浅/深主题和键盘导航检查；本轮未运行测试。

## 回滚

回滚本次涉及的前端布局/平台导航改动及本 Change Spec；无数据迁移或运行时状态需要回滚。
