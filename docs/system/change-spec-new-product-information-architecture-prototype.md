# Change Spec：new-product 信息架构演示页

日期：2026-08-31
状态：Implemented

## 当前现状

`docs/new-product/` 是独立的静态信息架构演示：入口页左侧展示页面目录，右侧 iframe 加载每个独立 HTML。它不连接产品 API，不修改正式 React、FastAPI、Tauri、SQLite 或 Agent runtime。

## 本次目标

- 桌面端页面从 5 个收敛为 D01、D03、D06、D09 四个。
- 删除团队空间节点与 D05 页面。
- D03 只用当前会话标题作为顶部语义，修正左侧选中态。
- Workspace 上下文移出输入框；权限、模型、语音、字数和发送操作水平对齐。
- 增加静态模型选择浮层，表达模型、模式、标签、成本和自定义模型入口。
- D01/D03 增加完整底部面板（命令行/运行日志）、右侧文件面板、上下/左右拖拽分隔条和右上角 hover 说明。
- 总览入口 `index.html` 只保留左侧分类页面目录和右侧 iframe，去除左上品牌头部。
- D01/D03 的 Agent、侧边文件面板、底部工作区面板采用并列分区；打开面板时压缩 Agent 可用区域，不使用覆盖式弹窗。
- 侧边与底部面板使用独立开关，互不影响；侧边支持左右拖拽，底部支持上下拖拽。
- D06 重构为插件、技能、连接器和应用四个主 Tab；每个 Tab 使用独立搜索语义、添加流程、内容结构和状态展示。
- 桌面端统一加载 `assets/desktop-polish.css`，补充 semantic token、Light/Dark 主题一致性、可访问焦点态、轻量状态反馈和 reduced-motion 降级。
- 侧边文件面板与 Agent 同高；底部面板覆盖 Agent 与侧边面板的总宽度，不能被侧边面板遮挡。

## 明确不做

- 不修改正式产品页面、路由、API、数据库或权限逻辑。
- 不实现真实模型切换、Workspace 访问或消息发送。
- 不改变云端和移动端页面目录。

## 影响范围与冲突检查

- 影响：`docs/new-product/` 页面目录、D01/D03/D06/D09 静态 HTML、共享样式/脚本、页面地图和 Stitch 提示词。
- 产品规则：无冲突；仍突出本地 Agent 会话和可验证的执行上下文。
- 数据模型/API：无变更。
- 本地/线上数据：无影响。
- 最小改动：删除 D05 引用与文件，只为 D03 增加必要结构和样式。

## 验收标准

- `pages/desktop/` 只有 4 个 HTML，入口目录不再出现 D05 或团队空间。
- D03 的新对话入口无选中态，当前会话有选中态。
- D03 顶部只显示“检查系统架构”和同排操作按钮。
- Workspace 行位于 composer 外；底部操作水平对齐；发送箭头居中。
- 点击模型按钮可打开模型浮层，且 Light/Dark 模式结构一致。
- D01/D03 的底部面板支持命令行/运行日志 Tab，侧边面板支持文件选择/预览，两个面板的分隔条可拖拽，右上角按钮有 hover 说明。
- 总览页不显示 Logo、NoteMeld 品牌头部或框架说明文字；左右/底部面板打开后与 Agent 呈并列布局，且开关互不干扰。
- 静态服务下入口和 4 个桌面页面均返回 200。
- `docs/new-product/design.md` 定义主题、组件、图标和动效契约；四个桌面页面的视觉规则保持一致。

## 风险与回滚

- 风险仅限静态原型视觉回归和失效页面引用。
- 回滚时恢复 D05 目录项/文件，并还原 D03 的旧顶部和 composer 结构；不涉及数据恢复。
