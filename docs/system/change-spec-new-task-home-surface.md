# 新对话首页背景与快捷建议布局

更新时间：2026-09-23

## 当前现状

- D01 新对话首页以深色背景承载居中的标题、四个快捷建议和共享 Agent 输入框。
- 桌面 CSS 将四张快捷卡片强制排成两列；Composer 在深色主题沿用通用白色容器的深色替代面，与首页背景明显不同。

## 目标与范围

- 深色主题下，首页 Composer 使用与首页相同的背景色和协调的边框色。
- 桌面宽窗口将四个快捷建议压缩为单行并降低卡片高度；窄窗口保留两列/单列响应式布局。
- 提高快捷建议标题、说明和按键提示在深色背景下的可读性。
- 保留现有提示点击行为、输入控件、模型/工作区选择和提交逻辑。

## 冲突与影响

- 只修改桌面前端 D01 样式，无 API、数据、模型状态或运行时行为变化。
- 使用现有表面、边框和文字语义色；不新增原语或状态。

## 验收

- 深色主题下 Composer 外表面与 D01 页面背景协调，边框不再呈现突兀的浅色轮廓。
- 宽桌面下四张快捷卡片同排展示，且比原双行布局更紧凑；小屏仍会折行。
- 深色主题下卡片标题、描述和快捷键有清晰对比度。
- 原有点击和输入行为不变。

## 验证与回滚

- 建议在 1440px 宽桌面窗口以及窄窗口检查浅/深主题与卡片布局；本轮不运行测试或构建。
- 回滚本 Change Spec 和相应 D01 CSS 即可；无持久化数据需要迁移或回滚。
