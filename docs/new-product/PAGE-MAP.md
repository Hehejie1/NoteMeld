# NoteMeld 多端页面与功能总表

这是 `docs/new-product/index.html` 左侧目录和 iframe 页面对应的页面地图。每个编号对应 `pages/desktop/`、`pages/cloud/`、`pages/mobile/` 或 `pages/apps/` 下的独立 HTML；A01/A02/A03/A04 是多端设计文档页面，其他页面是交互原型，不代表生产实现。

## 产品设计文档

| 编号 | 页面 | 核心功能 |
|---|---|---|
| A01 | 多端架构设计 | 展示桌面端、Cloud Web、移动端、Agent Worker、Workspace、Relay 和权限关系 |
| A02 | 多端数据库设计 | 展示三端 Workspace、会话、记忆、偏好、缓存和 Cloud 控制面数据职责 |
| A03 | 多端功能地图 | 展示桌面端、C01-C06 和移动端功能点、接口、数据表、状态流转和完成度 |
| A04 | 组件库设计 | 展示跨端设计元语、基础交互原语及其 HTML 参考实现 |

页面功能说明和元素绑定统一维护在 [`config/feature-registry.json`](./config/feature-registry.json)。首页左侧的“预览模式”用于正常操作原型；“讲解模式”根据 selector 绑定拦截功能元素点击，并弹窗展示功能说明、接口、数据表和状态。未登记的交互不能被当作已完成能力。

## 桌面端 Agent

| 编号 | 页面 | 核心功能 |
|---|---|---|
| D01 | 新对话 | 空白的新本地 Agent 会话；工作空间、附件、能力、权限、模型、语音输入和发送 |
| D03 | 会话列表与详情 | 会话列表中的当前会话；消息、工具调用、审批、队列、文件/产物、远程设备上下文、复制分支、收纳和删除 |
| D06 | 插件应用 | Skills、MCP、插件、Application、智能体、安装状态、权限和兼容性 |
| D09 | 设置页面 | 模型、主题、账户、设备、数据、安全、远程授权和 Agent 诊断 |

## 应用

“应用”是主框架中的一级入口。应用拥有自己的二级导航和业务工作区，但继续复用 NoteMeld 的 Token、基础原语、Application Host、权限和状态语义。插件能力仍由 D06 管理；迁移包、合并、索引重建和迁移任务不单独展示为应用页面。

| 编号 | 应用 | 核心功能 |
|---|---|---|
| APP01 | 笔记应用 | 笔记列表、笔记样式与模板、Wiki 知识图谱/文章/关系/重建、旧笔记与 Markdown 导入 |
| APP02 | 学习应用 | 学习空间、学习画布、掌握验证、复习、语义白板、卡片/关系和发布为笔记 |
| APP03 | 监控应用 | Token 用量明细、供应商筛选、任务聚合、部署状态、GPU/CUDA/MCP/自动启动和插件/转写健康 |
| APP04 | 系统运行 | Agent Turn 诊断、Application 实例/目录/外部文件权限、候选验证/审批、安全声明、更新、设备/LAN/Relay/远程帧 |

## 云端页面

普通用户和管理员使用同一界面；菜单、页面入口和操作按钮根据角色与 scope 显示。普通用户不能看到管理员管理入口。

| 编号 | 页面 | 核心功能 |
|---|---|---|
| C01 | 云端登录 / 申请访问 | 已有成员登录；未获权限用户提交邮箱、密码、姓名和申请说明，等待管理员审核 |
| C02 | AI 工作台 | 公共顶部导航、用户菜单、云端运行看板、会话状态、Workspace、搜索筛选和运行摘要 |
| C03 | 云端会话详情 | 复用桌面端对话模型，并增加后台运行、云端额度、共享权限和云端沙箱语义 |
| C04 | 人员管理 | 访问申请、已加入成员、管理员邀请、角色、账号状态和成员关联记录 |
| C05 | 设备管理 | 一次性配对凭证、公钥交换、设备授权、撤销、凭证状态和运行节点 |
| C06 | 设置页面 | 公共顶部导航；设置内容区左侧通用、空间管理、安全管理、日志排查分类，以及对应偏好、容量、授权和排查入口 |

## 移动端

移动端以 Agent 对话为主体；左上角打开工具/会话/用户抽屉，右上角进入新建、产物和更多操作。不使用底部 Tab 作为主导航。

| 编号 | 页面 | 核心功能 |
|---|---|---|
| M01 | Agent 首页 | 对话主体、会话抽屉、本地/云端/远程切换、任务摘要和 Agent 输入 |
| M02 | 会话详情 | 消息、模型、权限、文件、产物、更多操作和底部输入 |
| M03 | 设置首页 | 记忆库、主题、语言、字体、通知、日志和存储入口 |
| M04 | 记忆库 | 结构化记忆查看、复制和添加我的记忆 |
| M05 | 字体大小 | 预览、拖拽调节、跟随系统和确认保存 |
| M06 | 存储空间 | 分类占用、单项清理、全部清理和进度反馈 |

## 当前明确不进入页面的内容

- 远程 relay 不展示消息明文、未送达队列或云端持久化正文。
- 本地 secret、API key、Cookie、私有环境变量、设备私钥不进入分享清单。
- 非宿主设备上的 Skill、插件和未关联 Application 只展示不可用原因，不提供执行按钮。
- 招聘工作空间的内嵌浏览器、Skill、公司调研、简历 Markdown/HTML/PDF 是后续能力页面/应用入口，不能误认为 Application Protocol v1 已经支持。

## 讨论核对结论

- 桌面端现有实现还包含 Agent 诊断能力（session、turn、事件序号和运行状态）；本版先作为 D03 会话详情与 D09 设置的内部能力，不单独增加页面，避免目录膨胀。
- 桌面端主框架最终收敛为 D01、D03、D06、D09 四个宿主页面；APP01–APP04 是从主框架进入的独立业务应用，不是旧设置页的局部补丁。Workspace、文件/产物和远程设备上下文都在会话详情、应用或设置中按当前任务呈现，不再设置“团队空间”页面。
- 云端 C01–C06 共享同一套公共顶部：左侧 NoteMeld，中间 AI 工作台/云端会话/人员管理/设备管理/设置，右侧用户信息菜单。C04 的人员管理操作按管理员权限控制；普通用户仍可看到统一的信息架构但不获得管理操作。Workspace 作为 AI 工作台和云端会话的上下文，不单独增加页面。申请访问不是成员账号，审核通过后关联为同一成员身份记录。
- 移动端 M01–M06 是当前产品规划页面，不直接照搬当前 Web 前端路由。仓库中遗留的 M07/M08 页面不纳入当前入口目录；当前 Web 路由（如 `/new`、`/notes/:taskId`、`/settings/*`）是实现现状参考，不改变本版多端页面编号。

## 桌面端核心页面设计结论

D06/D09 与 D01/D03 复用同一套左侧栏：Logo、收起/通知/搜索、新对话、插件应用、设置、会话列表、连接状态和主题 Switch；点击对应入口只替换右侧工作区内容。

- D03 会话列表与详情：顶部只显示当前会话标题和上下文按钮；Workspace 位于输入框外；输入框内的权限、模型、语音和发送操作水平对齐。
- D06 插件应用：用 Tab 区分 Skills、MCP、插件、Application 和智能体；列表显示来源、版本、状态、兼容性和权限；详情区显示依赖、数据范围和最近错误，支持安装、更新、启用、禁用、卸载和重新授权。
- D09 设置页面：页面内采用设置分组导航，覆盖通用、主题、模型与提供商、权限/MCP、设备、数据、安全、Agent 诊断和关于；敏感信息、设备授权、数据清理和导入导出使用确认弹窗。
