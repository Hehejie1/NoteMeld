# A04 示例交互与分端展示修订

## 现状与范围

A04 已有参数表与 HTML 示例，但参数配置混入弹层、Input 把不限长度设成零、Mentions 跳过回填绑定、Drawer 缺少定位样式。仅调整原型页面、示例脚本与样式；不修改生产前端、API、数据库或运行时。

## 展示契约

- 参数表在前，代码演示在后。示例用带边框的卡片和平台标签组织。
- 相同形态使用“PC端 / 移动端”；日期、时间、选择器、表格、标签页、对话框、抽屉与穿梭框分端展示。
- 日期弹层保留日历、日期时间值、今天和确认。尺寸、状态、粒度等演示配置放在弹层外。
- 上传限制与文件类型配置放在上传区域外。
- 表格桌面采用列比较，移动端采用带标题和元数据的记录卡片；两端实例独立操作。
- Result 从 A04 组件目录移除，不删除其他页面业务结果展示。
- 图标参考 Ant Design 的分类，采用产品已包含的 Lucide 24px/2px/currentColor 图形；移动端扩大触控区域而非任意放大图标。

## 回归路径

1. Input 在不限长度时输入新内容；启用长度限制、清除和禁用，再恢复不限。
2. Mentions 输入 @，选中候选后回填；AutoComplete 选中后关闭列表并保留值。
3. DatePicker 两端打开、选择、清空、重选；改变外部尺寸与禁用日期配置后仍生效。
4. Slider 范围模式使用同一轨道的两个滑块；键盘调整上下界并保持顺序。
5. Select 左文字、右箭头；Switch 在文字/图标模式下切换状态。
6. Transfer 两侧选项移动；Table 分端分页与选择；Tabs 分端独立切换。
7. Drawer/Modal 打开后面板在遮罩上方；取消、关闭、Escape 返回触发器。
8. Radio、Tree、Tooltip、Badge、Spin、图标目录逐项截图检查。

## 风险与边界

旧示例通过根节点查找配置，移动配置必须保持在所属示例根节点内，保留已有事件处理器。生产平台仍各自实现，不声称此原型已覆盖 Ant Design 全部 API。

全站产品文档校验目前报告 APP01–APP04 缺失及 C07 registry/live 绑定问题；与 A04 本次修改无关，不能作为本次全部通过的证据。

回滚仅撤销本次 A04 样式、脚本和资源版本改动，无数据迁移。
