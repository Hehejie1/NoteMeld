# NoteMeld 云端产品语言

该上下文定义 NoteMeld 云端人员准入、可信设备和云端会话中的核心概念，避免把申请、成员、设备和运行节点混为一类。

## 人员准入

**访问申请**：
尚未成为成员的人提交的准入请求，包含邮箱、密码凭证、姓名和申请说明；它不是账号。
_Avoid_: 注册、用户账号

**成员**：
已获得 NoteMeld 云端访问权限的身份记录，可以通过申请审核或管理员邀请产生。
_Avoid_: 申请人、账号申请

**管理员邀请**：
管理员先指定邮箱、受邀者再通过一次性链接验证邮箱并设置密码的准入方式。
_Avoid_: 管理员创建密码、手动注册

## 设备信任

**配对凭证**：
用于建立设备与云端账户首次信任关系的一次性、短时有效凭证，不是长期通信密钥。
_Avoid_: 永久密钥、设备私钥

**第三端设备（用户设备）**：
由成员持有并与云端账户配对的桌面或移动设备。Cloud 不按桌面/移动端区分其设备生命周期：两者均上报心跳、接收同组织在线目录，并通过 Grant 获得远程控制能力。
_Avoid_: 运行节点

**运行节点**：
为 Agent 提供远程计算能力的云服务器、GPU 节点或专用执行节点。
_Avoid_: 用户电脑、普通设备

## Agent 运行

**云端会话**：
由云端 Agent 执行并可在浏览器关闭后继续运行的会话，文件和命令行均处于云端 Workspace 与沙箱范围内。
_Avoid_: 本地会话、远程设备会话

**沙箱终端**：
云端会话底部、以分配文件夹（workspace root）为根的受限 shell。只能用根内相对路径；sudo/绝对路径/`..` 越界被拒绝；正文与思考经 SSE 流式返回。
_Avoid_: 可访问系统目录的 SSH 终端

**分配文件夹**：
为某用户某工作区分配的独立磁盘根目录 `workspaces/{user_id}/{workspace_id}`，是文件 API 与终端共同的逻辑根（root-jail）。
_Avoid_: 用户自定义任意路径、系统根

**远程设备会话**：
通过已配对用户设备及其授权能力执行操作的会话。
_Avoid_: 云端会话

## 模型与凭据

**组织模型目录**：
当前 Cloud 团队内共享的模型名称、Provider 地址、启用状态与默认 Auto 策略。Cloud 会话及连接 Cloud 的本地端只从该目录选择模型。
_Avoid_: 跨端密钥同步、个人本地 Provider

**端侧模型凭据**：
桌面或移动端为自己的本地 Provider 保管的 API Key。它不进入组织模型目录、配置同步或扫码材料。
_Avoid_: 组织共享凭据

**临时添加材料**：
用于扫码添加 Cloud 连接或模型配置的一次性、短时有效信息；它只帮助当前端完成添加，不能包含或沉淀长期 Token、模型 API Key、设备私钥或会话密钥。
_Avoid_: 配置备份、密钥迁移

## Workspace 与执行目标

**Workspace**：用户明确注册的文件与产物边界，包含一个或多个受控文件夹引用、能力和审批策略；Workspace 不保存会话正文。

**执行目标**：Agent turn 实际运行的位置。它可以是本机 local folder、Windows WSL distro/path、SSH remote host 或已配对用户设备；执行目标必须报告 availability 和 transport。

**全局会话**：由桌面/Cloud authority 持久化的 conversation、turn、event、tool、approval 和 artifact metadata。文件正文和命令执行结果留在执行目标，引用回全局会话。
