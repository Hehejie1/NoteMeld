# NoteMeld 多端界面目录

这是用于梳理 NoteMeld 多端页面数量、页面关系、功能边界和实现映射的产品原型目录，不是生产运行时本身。

`config/feature-registry.json` 是页面功能说明、接口/能力、数据表、状态、架构层和待确认项的配置源。首页左侧提供“预览模式”和“讲解模式”：预览模式用于操作页面，讲解模式点击已登记的页面元素后显示对应的功能说明和实现映射；未登记元素会明确提示，不能按元素顺序猜测。A01/A02/A03/A04 分别承载多端架构、多端数据设计、多端功能地图和组件库设计。A04 左侧提供设计元语与基础原语目录，右侧渲染可操作的 HTML 参考实现。主框架中的“应用”入口包括 APP01 笔记、APP02 学习、APP03 监控和 APP04 系统运行；插件能力仍归 D06 管理。

交互绑定支持两级覆盖：如果具体按钮/链接有自己的功能 selector，讲解模式展示控件自身的说明；如果没有，则继承最近的已登记表单、面板或工作区容器说明。这样一个提交表单内的取消、提交和状态反馈可以共享同一功能契约，同时仍可为特殊按钮添加更具体的功能 ID。

可以在仓库根目录运行 `python3 scripts/cloud/validate_product_docs.py`，检查功能配置引用的多端页面、Cloud 接口、数据表和 selector 是否仍然存在。配置中的 `prototype`、`needs_backend` 和 `missing` 是明确的未完成或原型状态，不会被校验器误判为已实现。

## 查看方式

在本目录启动静态服务器：

```bash
./start.sh
```

然后打开 `http://127.0.0.1:8765/`。

首页只负责目录浏览：左侧按桌面端、云端、移动端分类列出所有页面，右侧通过 iframe 加载对应的独立 HTML 页面。页面内部的跨页链接会同步首页左侧选中项；分隔条可以拖拽调整目录宽度。

页面清单和功能范围见 [PAGE-MAP.md](./PAGE-MAP.md)。
