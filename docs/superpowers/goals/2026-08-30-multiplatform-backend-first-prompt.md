# NoteMeld 多端同步：Backend-first 目标模式提示词

你是本项目的主程工程师。请在 `NoteMeld` 产品仓库内，先完成可商用的云端与共享客户端后端基础能力；本阶段不要实现移动端原生 UI，也不要为了演示复制 Agent loop。

## 目标

实现 FastAPI 云端控制面与桌面/Web/Python 共享适配层，使以下链路可端到端联调：管理员初始化和登录、用户 CRUD、设备注册与心跳、token/PAT 管理、会话创建/同步/归档/恢复/硬删除/复制分支、每会话串行命令队列、离线失败与恢复、设备双向控制授权、危险操作审批、workspace 安全读写、云端 Agent、加密中继、LAN 优先后云端转发。

## 约束

- 账户使用环境变量配置的超管账号密码启动；普通用户由后台创建。用户名不是唯一键，设备 ID 才是设备唯一标识。
- 远端 HTTP 必须 HTTPS；token 只能加密保存（平台密钥由 Keychain/Keystore/Tauri/浏览器安全存储提供），禁止 localStorage 明文。
- 云端中继只转发不落盘；中继帧由端到端 AEAD 加密，服务端不得解密业务 payload。宿主离线时立即返回失败。
- workspace 默认本地磁盘，读取可用；写入/删除必须显式授权。拒绝绝对路径、`..`、反斜杠、符号链接逃逸，并提供原子写入、崩溃恢复、备份恢复、容量/文件数配额。
- 会话事件支持快照 + 增量分页；归档和硬删除语义必须区分；复制分支是独立完整会话。
- 所有跨端协议、错误码、权限 scope、状态机和数据模型写入 `docs/system/`，并与 OpenAPI/测试保持一致。

## 执行顺序

1. 先阅读根目录及 `NoteMeld/AGENTS.md`、`CLAUDE.md`、system docs、现有 requirements/spec/plan，检查工作区状态。
2. 盘点已有实现，补齐缺口；优先修改 `cloud/`、`backend/app/cloud_sync/` 及其测试，保持 SDK/Agent runtime 单一来源。
3. 为认证、设备、会话队列、workspace、relay、审批、云端 Agent 和配置校验分别增加契约测试与失败路径测试。
4. 增加共享客户端最小适配（Python/Web），确保 API 超时、网络异常、重放、越权、过大请求和离线状态有稳定错误语义。
5. 运行最小到完整验证：云端/后端测试、前端契约测试、类型检查；记录环境限制，不得声称未运行的平台通过。
6. 最后输出变更摘要、风险/未完成项、启动命令、环境变量示例和下一阶段（桌面、Android、iOS、Harmony、Web UI）拆分建议。

## 验收标准

- 新部署仅配置管理员环境变量即可启动；弱密码、危险 CORS、非法远端 URL、无效配额/超时配置启动失败。
- 未授权用户不能访问管理 API、其他用户会话、workspace 或危险工具；审批过期/重复消费安全失败。
- 同一会话多设备命令严格串行；宿主离线不会悄悄排队到云端，已接收队列可在受控端重启恢复。
- 中继服务无法从数据库或日志恢复明文 payload；帧 nonce/序号/epoch/会话元数据参与认证，重放和越权帧被拒绝。
- 所有写文件均原子落盘，异常重启后临时文件可清理，路径穿越和 symlink 攻击有测试覆盖。
- 测试失败时给出真实失败原因和后续动作，不修改或清理用户已有改动。

请直接在当前 worktree 实施并验证；只有在上述验收标准达到后才报告“完成”。
